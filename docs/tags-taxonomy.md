# Taxonomia de Tags das Questões

As tags das questões seguem uma taxonomia unificada de ~67 temas, organizada por área de conhecimento. O objetivo é manter consistência para que o desempenho por assunto seja comparável entre anos e provas.

## Matemática

| Tag | Conteúdos representativos |
|-----|--------------------------|
| `aritmética e números` | números racionais, decimais, divisibilidade, porcentagem, razão, proporção, regra de três |
| `álgebra` | equações, inequações, sistemas, expressões algébricas |
| `funções` | função linear, quadrática, logarítmica, exponencial, trigonométrica, domínio e imagem |
| `geometria plana` | triângulos, círculos, áreas, perímetros, ângulos, figuras planas |
| `geometria espacial` | volumes, prismas, pirâmides, cilindros, esferas, troncos |
| `geometria analítica` | plano cartesiano, reta, parábola, distâncias, equação da circunferência |
| `trigonometria` | seno, cosseno, tangente, lei dos senos e cossenos, identidades trigonométricas |
| `estatística` | média, mediana, moda, desvio padrão, leitura de gráficos e tabelas |
| `probabilidade` | eventos simples e compostos, probabilidade condicional, eventos independentes |
| `análise combinatória` | princípio multiplicativo, permutações, arranjos, combinações |
| `matemática financeira` | juros simples e compostos, desconto, financiamento, porcentagem aplicada |
| `sequências e progressões` | PA, PG, sequências numéricas, indução |

## Diretrizes de mapeamento

- Nomes de autores, filósofos, ou personagens históricos **não são tags** — usar a categoria temática correspondente.
- Tags cruzadas entre áreas (ex.: `física` em questões de matemática) devem ser corrigidas para a tag da área correta.
- Cada questão deve ter entre **2 e 4 tags** da lista acima.
- Prefer tags mais específicas quando possível (ex.: `mecânica newtoniana` em vez de `física`).
