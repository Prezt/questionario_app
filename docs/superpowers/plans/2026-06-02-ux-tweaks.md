## Task 3: Show overall hit-rate % on year pills

**Files:**
- Modify: `src/App.jsx:1665-1685` (year-pill rendering)
- Modify: `src/App.css` (append new rules)

- [ ] **Step 1: Add a helper that computes the overall percent for a year**

Place this helper next to the existing `yearTier` function (`src/App.jsx:1548-1559`). The logic mirrors `yearTier` but returns a percent instead of a tier name. Add immediately after `yearTier`:

```js
const yearPercent = (year) => {
  if (selectedTest !== 'ENEM') {
    const r = getResult(selectedTest, year)
    return r && r.total ? Math.round((r.score / r.total) * 100) : null
  }
  const r1 = getResult(selectedTest, year, 1)
  const r2 = getResult(selectedTest, year, 2)
  if (!r1 && !r2) return null
  if (!r1 || !r2) {
    const r = r1 ?? r2
    return r.total ? Math.round((r.score / r.total) * 100) : null
  }
  const totalScore = r1.score + r2.score
  const totalTotal = r1.total + r2.total
  return totalTotal ? Math.round((totalScore / totalTotal) * 100) : null
}
```

- [ ] **Step 2: Render the percent under the year**

Modify the year pill in `src/App.jsx:1665-1685`. Current code:

```jsx
<div className="home-filter-pills home-year-grid">
```

Change to:

```jsx
<div className="home-filter-pills home-year-grid">
  {availableYears.map((y) => {

    const pct = yearPercent(y)
    return (
      <button
        key={y}
        type="button"
        className={`home-filter-pill home-year-pill ${selectedYear === y ? 'active' : ''} ${tier ?? ''}`}

```

Wrapping `{y}` and the tier icon in `.home-year-label` keeps them side-by-side, and the new `.home-year-pct` sits on its own line below.
